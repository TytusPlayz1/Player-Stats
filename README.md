# Player Stats

A lightweight Netlify-ready Minecraft player stats landing page for a public-facing profile and leaderboard experience.

## Local preview

Open `index.html` directly in a browser, or serve the repo locally with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Netlify

1. Push this repo to GitHub.
2. Import it into Netlify.
3. Set the publish directory to `.`.
4. Deploy.

This project is a static site, so no build step is required.
